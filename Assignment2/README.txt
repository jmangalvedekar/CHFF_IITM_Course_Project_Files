This folder contains 3 folders, two input and one output. One of the input folders contains all input files with code in txt format while the other contains code in .cpp and and .py formats. The output folder contains all the plots asked in the Assignment.

Pre-requisites to run the assignment codes: C++ compiler and Python interpreter.

Procedure to run the code:
1) Run the cpp files first, a text file will be created where the temperature values will be stored.
2) Run the corresponding python files which will load the data from the text file and plot the results.
3) For the 2nd question(Assignment2_2 file), make sure that the value of n (the number of elements) and other input paramters are same in the cpp file: Assignment2_2 and the python file: Plot2_2.
4) Any errors faced while running the cpp codes will be most likely due to the variables that I have defined(gamma, beta and alpha) already being defined variables in the cmath class. To solve it, just add an underscore or change the name of the variable wherever it exists.

For details regarding the discretization and development of matrices, you may go through the hand written write-up pdf file.
