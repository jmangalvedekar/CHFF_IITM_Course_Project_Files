# CHFF_IITM_Course_Project_Files
This repository contains my assignments and course projects that I solved in C++ while attending the Computational Heat and Fluid Flow Course at IIT Madras (By Prof. Kameswararao Anupindi).

The 2nd Assignment is simulating 2D diffusion equation by employing line by line tridiagonal matrix algorithm (LBL-TDMA). This forms the base for the course project titled "CFD Simulation of Unsteady 2D Heat Diffusion on a Square Plate using Various Time Stepping Schemes". The finite volume method (FVM) is used for discretizing the space domain in all codes. To understand the LBL_TDMA, readers are advised to go through the Assignment 2 report in the Assignment 2 folder. They can move on to the course project file after this code. 

Core programs are written in C++ and Python matplotlib is used for post-processing.
